 
# Forex Converter

**Developed by: ARYANRAJ MALEPU**

## 📌 Project Overview

Forex Converter is a web-based currency conversion application designed to provide a simple and convenient way to convert values between different currencies.

The project provides a user-friendly interface where users can enter an amount, select currencies, and perform currency conversion.

## ✨ Features

* Currency conversion interface
* Simple and user-friendly design
* Amount input for conversion
* Currency selection
* Web-based application
* Lightweight and easy to use
* Responsive interface for convenient access

## 🛠️ Technologies

The project is implemented as a web application using:

* **HTML** – Structure and content of the application
* **Web-based UI** – User interaction and currency conversion interface

## 🚀 How to Run

Since this is a web-based project, no complex installation is required.

### Method 1 — Open Directly

Download or clone the repository and open `index.html` in a web browser.

### Method 2 — Clone Using Git

```bash
git clone https://github.com/ayvan6/forexconverter.git
```

Move into the project directory:

```bash
cd forexconverter
```

Open the main page:

```bash
xdg-open index.html
```

You can also double-click `index.html` and open it using a modern web browser.

## 🌐 Run Using a Local Server

For a better development environment, you can use Python's built-in HTTP server.

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## 💱 How to Use

1. Open the Forex Converter application.
2. Enter the amount you want to convert.
3. Select the source currency.
4. Select the destination currency.
5. Perform the conversion.
6. View the converted value.

## 🎯 Project Objective

The objective of the Forex Converter project is to create a simple web-based application for currency conversion while demonstrating the development of an interactive web interface.

The project can also serve as a foundation for extending the application with additional currencies, live exchange-rate APIs, improved UI components, and additional conversion features.
